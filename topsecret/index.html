Dropbox

画像を Dropbox の「動画用素材」フォルダ（いちばん上）に 保存します。フォルダが なければ 作ります。同じ 名前が あれば 名前を かえて 保存します（上書きしません）。

はじめに 1回だけ、Dropbox の 開発者ページで アプリを 作って App key を 入れます（作りかたは topsecret/src/README_dropbox.md）。つなぐ ときは Dropbox の 画面に 移り、「許可」を 押すと もどって きます。

ROM

NERversion（改造ROM）の .sav を読みこむと、ランダマイザで入れかわった野生のポケモンが、どこで・どの方法で・何Lvで・何%で出るかを計算します。読みこんだ内容（入れかえの番号・つかまえた/みたポケモン）はこの端末に保存し、セーブそのものは保存しません。「出ないポケモン」は、野生で出ず、野生で出るポケモンの進化・タマゴでも手に入らないポケモンです（交換・配布は考えていません）。

ROM と 説明書は、自分の Dropbox・GitHub の ページを ひらきます（ログインした 本人だけ 見られます）。共有リンクでは ありません。項目を ふやす ときは topsecret/src/app.js の LINKS に 1行 足します。
