# 画面の上の数（捕まえた・見つけた）の型紙 hdr の作り方（2026.10.28a）

型紙 `prof/<作品>_full.json`（と `<作品>.json`）の `hdr`：
- `parts`：[x0, x1, y]（型紙の座標。一覧と同じ写し方 m の座標で、上の画面は負の x になることがある）。順番は **捕まえた → 見つけた**。
- `sets`：図鑑ごとに数の場所がちがう・図鑑ごとの数が並ぶ画面（RS/E のホウエン・ぜんこく、剣盾の3つの図鑑、BW/BW2 の2つの画面の作り）。`d` は図鑑のキー（null なら、その画面の図鑑か、いま選んでいる図鑑）。set ごとに `tm`・`y0`/`y1`・`min`/`gap`・`num` を持てる。
- `tm`：0〜9 の字の形（12×16）。録画の字の平均。録画に出てこない字は、一覧の番号の見本（`P.tm`）と字体が同じとき（相関の中央値 0.85 以上）だけ使う。ないときは null（その字の数は読まない＝くらべない）。
- `min`/`gap`：いちばん似ている字の相関・2番目との差。`lead0`：0 から始まる数（Z-A の 054）。`dexMin`：図鑑の見出しの似かたがこれ以上なら、その図鑑の画面とする（BW/BW2）。

作り方（作業場所の Chromium、harness は 8766）：
1. 録画から 1秒ごとの画像：`ffmpeg -i 動画 -vf fps=1 tmpx/h_X/%03d.png`
2. 型紙の座標の画像で場所を見る：`python tools/hdr_hm.py 作品 画像 out.png x0 x1 y0 y1` → `python tools/hdr_grid.py out.png 拡大 x0 y0 目盛り`
3. 見本を作る：`python tools/hdr_mkhdr.py 作品 '{"y0":-6,"y1":6,"parts":[[..]],"min":0.8,"gap":0.1}' '[["捕まえた","見つけた"]]' out.json 画像...`（y は ±4 の範囲で探す。`noP` で一覧の見本を y 探しに使わない、`tmFrom` でほかの作品の一覧の見本を使う）
4. 確かめる：`python tools/hdr_ht.py 作品 out.json 画像...`（読めた数ごとの枚数。まちがった数が出ないこと）

作った作品（運営者の録画の数）：赤緑青ピカ 74/137、金銀クリスタル 150/209、RS 223/268、E ホウエン 202/202・ぜんこく 386/386、DP 194/300、BW 242/392、BW2 82/290、XY 134/380、ORAS 155/262、BDSP 115/201、剣盾 ガラル 288/360・ヨロイ島 126/161・カンムリ雪原 133/173、Z-A 54/62、SV（2026.10.27h）、LA 239/239（2026.10.28l。上の数は左から 見つけた・捕まえた（登録だけもふくむ）・自分で捕まえた。parts は2番目→1番目）。
まだ：FRLG（一覧の画面に数がない）、HGSS（数は図鑑を開いた最初の画面だけ）、SM・USUM（型紙でない読み方）、Let's Go（録画が一覧の画面でない）。
