# SV の画面の左上の数（捕まえた・見つけた）の字の見本（型紙 sv の hdr）

- 0・1・3・6・7・8・9：運営者の録画（パルデア 380/393・キタカミ 169/189・ブルーベリー 160/176 の画面、1秒ごと 61枚）で切り出した字の平均。
- 2・4・5：録画に出てこないので、字の形が近い Gothic A1 Bold で同じ大きさに描いて切り出した（録画の字 0・1・3・6・7・8・9 との相関が 0.89 以上で、いちばん近い字体）。
- 確かめたこと：録画の字 360 字がすべて正しく読め、2番目の字との差は 0.23 以上。ほかの 280 の太字の字体で描いた字も 89% が正しく読めた。
- 読み方は dxt.js の dxtHdr（字ごとに、平均を引いて大きさをそろえた形の相関。min より似ていて、2番目と gap 以上はなれていること）。
- cnt：図鑑ごとに、画面の数にかぞえる番号の上限（ブルーベリーは 241〜243 がかぞえられない。棚の印と画面の数をくらべて確かめた：1〜240 で 捕まえた160・見つけた176）。
