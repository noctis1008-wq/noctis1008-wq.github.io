# NER Converter

**バージョン: v8**(2026-09-21 / 変更履歴は `CHANGELOG.md`)

日本語版ポケットモンスター 金・銀・クリスタルのセーブデータを、3DS VC版で使用できる `sav.dat` に変換するWebツールです。

## 対応
- 日本語版 ポケットモンスター 金・銀・クリスタル
- 実機・mGBA等から抽出したセーブデータ
- ブラウザ内で変換処理を実行

## プライバシー
セーブデータはサーバーへアップロードせず、ブラウザ内で処理します。
広告配信にはGoogle AdSenseを使用しています。詳細はサイト内の「プライバシーポリシー」を確認してください。
